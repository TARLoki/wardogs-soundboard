Bei 150–200 % klingen manche Clips gequetscht oder leicht verzerrt. Das ist der Preis für die Lautstärke – am besten herantasten.

Klick spielt ab, nochmal klicken stoppt. Über ✎ Sound (Link, Datei, Aufnahme, Text → Sprache), Titel, Bild oder Emoji festlegen – Sound- und Bilddateien lassen sich auch direkt auf eine Kachel ziehen. Ersetzte Sounds landen in sounds/<Seite>/_alt.

  • wird geprüft …

Der Testton geht ohne Push-to-Talk ins Kabel. In mmsys.cpl → Aufnahme muss sich dabei der Pegel bei CABLE Output bewegen.

Einrichtung Schritt für Schritt

1

Python installieren

Installer von python.org/downloads laden. Im ersten Fenster unten „Add python.exe to PATH“ anhaken, dann „Install Now“.

Danach ein neues Terminal öffnen und mit python --version prüfen.

2

Pakete installieren

Im Terminal (PowerShell):

cd ""
python -m pip install -r requirements.txt
3

VB-Cable installieren

  1. vb-audio.com/Cable öffnen und das ZIP für Windows laden.
  2. ZIP entpacken, VBCABLE_Setup_x64.exe per Rechtsklick „Als Administrator ausführen“.
  3. „Install Driver“ klicken und den Rechner neu starten.

Danach gibt es das Wiedergabegerät CABLE Input und das Aufnahmegerät CABLE Output.

4

Windows-Ausgabe prüfen

Win + R → mmsys.cpl → Reiter Wiedergabe: dein Headset muss Standardgerät sein, nicht CABLE Input. VB-Cable stellt sich bei der Installation gern selbst als Standard ein.

5

Mikrofon im Soundboard

Das Soundboard nimmt dein Mikrofon auf und reicht es zusammen mit den Sounds ins Kabel weiter. Verwendet wird: . Ein bestimmtes Mikrofon legst du oben in soundboard.py bei MIC_DEVICE fest, z. B. MIC_DEVICE = "QuadCast" – ein Namensteil reicht.

Alle Gerätenamen zeigt python soundboard.py --list.

6

Soundboard starten

start.bat doppelklicken oder python soundboard.py. Das Konsolenfenster offen lassen, solange du spielst – sonst hört dich im Spiel niemand.

Reagiert das Numpad im Spiel nicht: Soundboard als Administrator starten.

7

WARDOGS einstellen manuell

  • Mikrofon / Eingabegerät: CABLE Output (VB-Audio Virtual Cable)
  • Ausgabe: dein Headset (unverändert)
  • Push-to-Talk: das Soundboard hält beim Abspielen automatisch „“ gedrückt – aber nur, wenn ein Fenster mit „“ im Titel aktiv ist.

Steht in der Konsole „PTT übersprungen, aktives Fenster: …“, den dort genannten Titel in PTT_WINDOW eintragen. Alternativ im Spiel auf Sprachaktivierung umstellen.

8

Discord einstellen manuell

Benutzereinstellungen → Sprache & Video → Eingabegerät ausdrücklich auf dein Mikrofon () stellen, nicht auf „Default“. Dann hört Discord nur deine Stimme, keine Sounds.

9

Sounds belegen

  • Auf myinstants.com einen Sound öffnen, Adresse kopieren, im Soundboard auf ✎ klicken, einfügen, „Laden“.
  • Oder eine WAV/MP3-Datei aus dem Explorer auf eine Kachel ziehen.
  • Oder Dateien in den Ordner sounds legen – Präfix bestimmt die Taste: 1_…9_, 0_, komma_, geteilt_, mal_, minus_, plus_, num_.
  • Weitere Quellen im Dialog: Datei …, ● Aufnehmen (über dein Mikrofon, Stille wird abgeschnitten) und Text → Sprache (Windows-Stimme). Mit Funk-Effekt klingt es wie über Funkgerät.
  • Bild oder Emoji: über ✎ (Datei, Strg+V, Bild-Link, Bibliothek) oder Bild direkt auf die Kachel ziehen. Es hängt am Sound; alle Bilder bleiben in sounds\images und lassen sich wiederverwenden.
  • Titel: über ✎ frei überschreibbar. Leer = automatisch (Myinstants-Seitentitel, Datei-Metadaten oder Dateiname). Wird der Sound getauscht, gilt wieder der automatische Titel.
10

Testen manuell

  1. Oben „Testton abspielen“ – du hörst ihn leise im Headset.
  2. mmsys.cpl → Reiter Aufnahme → der Pegel bei CABLE Output bewegt sich beim Testton und beim Sprechen.
  3. Im Spiel einen Mitspieler fragen, ob Stimme und Sounds ankommen.
11

Desktopverknüpfung optional

verknuepfung_anlegen.py im Soundboard-Ordner doppelklicken. Auf dem Desktop erscheint „WARDOGS + Soundboard“ mit dem WARDOGS-Symbol.

  • Startet das Soundboard minimiert in der Taskleiste (ohne Browser), danach WARDOGS über Steam.
  • Läuft das Soundboard schon, wird es nicht doppelt gestartet.
  • Wird WARDOGS geschlossen, beendet sich das Soundboard nach ca. 20 Sekunden von selbst.
  • Die Oberfläche erreichst du über ein Lesezeichen auf http://localhost:8765.

Klappt etwas nicht, steht in launcher.log im Soundboard-Ordner, was passiert ist.

Bedienung

  • Numpad 0–9 , / * - + Num: Sound abspielen, gleiche Taste nochmal: stoppen
  • Numpad Enter: alles stoppen
  • Bild ↑ / Bild ↓: vorherige / nächste Seite – der Seitenname wird im eigenen Headset angesagt
  • Seiten: über ＋ neue Seite anlegen (leer oder mit Kommando-Vorlage), über ⚙ umbenennen, verschieben, löschen
  • Neue Versionen: Das Soundboard fragt beim Start und alle 12 Stunden bei GitHub nach und zeigt oben einen Hinweis mit Download-Link. Installiert wird nichts automatisch. Abschalten: CHECK_UPDATES = False.
  • Lautstärke und „Ordner neu laden“: in der Soundboard-Ansicht. Über 100 % wird verstärkt, ein Soft-Limiter verhindert dabei hartes Übersteuern. Leise Sounds werden beim Laden automatisch angehoben.
  • Bedienung vom Handy: in soundboard.py WEB_HOST = "0.0.0.0" setzen, dann http://<PC-IP>:8765 im Handy-Browser öffnen

Fehlerbehebung

„Python wurde nicht gefunden“

Python ist nicht installiert oder nicht im PATH. Neu installieren mit Häkchen „Add python.exe to PATH“, danach neues Terminal öffnen.

„No module named …“

Pakete fehlen: Schritt 2 im Ordner des Soundboards ausführen. python -m pip statt pip verwenden.

„Smart App Control hat eine Datei blockiert“

Rechtsklick auf die heruntergeladene ZIP → Eigenschaften → „Zulassen“ → neu entpacken. Oder direkt python soundboard.py starten.

Im Spiel hört niemand die Sounds

Mikrofon im Spiel muss CABLE Output sein (Schritt 7). Bei Push-to-Talk prüfen, ob die Konsole „PTT übersprungen“ meldet. Pegel mit dem Testton prüfen (Schritt 10).

Im Spiel hört mich niemand mehr sprechen

Das Soundboard muss laufen, und im Check muss „Mikrofon gefunden“ grün sein. Ohne Soundboard kommt über CABLE Output nichts an.

Discord überträgt die Sounds mit

Discord-Eingabe steht auf CABLE Output oder „Default“. Ausdrücklich das Mikrofon wählen (Schritt 8). Bei offenem Headset ggf. MONITOR_VOLUME senken.

Desktopverknüpfung startet das Soundboard nicht

launcher.log im Soundboard-Ordner ansehen. Einmal python soundboard.py direkt starten und prüfen, ob dort eine Fehlermeldung erscheint. Wurde der Ordner verschoben, die Verknüpfung neu anlegen.

Echo oder Pfeifen

Windows-Standardmikrofon oder -ausgabe ist das VB-Cable. Schritt 4 und 5 prüfen.

Platz

Quelle: Myinstants- oder MP3-Link, Datei, eigene Aufnahme oder Text → Sprache (Windows-Stimme). Ein neuer Sound setzt Titel, Bild und Emoji zurück.

Oder ein Bild mit Strg+V einfügen bzw. direkt auf die Kachel ziehen.

Bild und Emoji hängen am Sound. Alle Bilder bleiben in der Bibliothek und lassen sich wiederverwenden.
